# Data-Center-Network-Lab
Data center network design and configuration using Cisco Packet Tracer

Overview

This project simulates a data center network environment using Cisco Packet Tracer. It focuses on network segmentation, gateway redundancy, Layer 2 loop prevention, link aggregation, secure remote device management, and access-layer security.

The lab demonstrates practical networking concepts commonly used when designing and managing switched network infrastructure.

Technologies Implemented:
- VLANs: Segment the network into separate logical broadcast domains.
- Inter-VLAN Routing: Enable communication between VLANs through Layer 3 switching.
- HSRP (Hot Standby Router Protocol): Provide default gateway redundancy and improve network availability.
- STP (Spanning Tree Protocol): Prevent Layer 2 switching loops in redundant network topologies.
- EtherChannel / LACP: Aggregate physical links into logical connections to increase available link capacity and provide link redundancy.
- SSH: Enable secure remote access to network devices for administration.
- Port Security: Restrict access to switch ports based on configured MAC address security policies.

Project Objectives:
- Design and simulate a data center network topology.
- Implement VLAN-based network segmentation.
- Configure inter-VLAN communication using Layer 3 switching.
- Provide gateway redundancy using HSRP.
- Prevent Layer 2 loops using STP.
- Configure link aggregation using EtherChannel and LACP.
- Enable secure remote device management through SSH.
- Apply port-level security controls using Port Security.
